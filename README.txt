CONVITE.EXE — Emanuella Rodrigues Bandeira

Projeto de convite interativo, responsivo e estático, com a foto enviada incorporada visualmente ao layout retrô.

Como abrir localmente:
1. Extraia o arquivo ZIP.
2. Mantenha index.html e foto-emanuella.webp na mesma pasta.
3. Abra index.html no navegador.

Como funciona:
- A foto enviada aparece como imagem principal do convite, em uma moldura retrô.
- O botão “NÃO” foge do mouse e do toque no celular.
- Ao clicar em “SIM”, aparece um campo para escolher o horário preferido de saída.
- O botão “VER PASSAGENS” abre a página da QueroPassagem para conferir horários disponíveis para 06/11/2026.
- O horário selecionado é uma preferência visual; ele não é enviado nem reservado automaticamente no site externo.

Como publicar:
- Vercel: importe o repositório/pasta como projeto estático. Não é necessário comando de build; deixe a raiz apontando para a pasta que contém index.html.
- GitHub Pages: envie index.html e foto-emanuella.webp para a raiz do repositório e habilite Pages.

Não há dependências de backend ou instalação de pacotes.
A tipografia externa usa Google Fonts; caso esteja offline, fontes locais alternativas serão usadas.
